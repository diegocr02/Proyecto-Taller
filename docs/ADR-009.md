# ADR-009 · Copia de solo revisión de la base en MySQL de XAMPP

Estado: Adoptado (registrado a posteriori por ingeniería inversa)   Fecha del registro: 2026-11-27

## Contexto

El equipo está acostumbrado a revisar datos en phpMyAdmin (XAMPP), pero la app usa SQLite (ADR-001, ADR-002) y no necesita MySQL.

## Alternativas consideradas

1. Migrar la app a MySQL: implicaba cambiar los repositorios, el Servidor MCP, el seed, las pruebas y varios ADR. Se descartó por ser un cambio grande.
2. **Un script que copie la base SQLite a una base MySQL aparte, solo para revisarla.**
3. Usar un visor de SQLite (DB Browser): funciona, pero no es la herramienta que conoce el equipo.

## Decisión

Se adopta la alternativa 2: `data/exportar_a_xampp.py` lee `data/taller.db` con `mode=ro`, genera las sentencias `CREATE TABLE` (InnoDB, utf8mb4, con claves foráneas) y los `INSERT`, y las ejecuta con `mysql.exe`. Cada vez borra y vuelve a crear solo la base `jorge_motors_app`. Se configura con `XAMPP_MYSQL`, `XAMPP_USUARIO`, `XAMPP_CLAVE` y `XAMPP_BD`.

## Consecuencias

- *Positivas:* los datos se ven en phpMyAdmin sin tocar la app; las tildes se conservan (verificado el 2026-11-27).
- *Negativas:* la copia no se actualiza sola, y lo que se cambie en phpMyAdmin no llega a la app. Hay que correr el script cada vez que se quiera revisar.
- Las bases `jorge_motors`, `jorge_motors_dev` y `jorge_motors_test` de la misma instancia de MySQL son de otros trabajos, y el script no las toca.
