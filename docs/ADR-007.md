# ADR-007 · Guardar cada comparación de conteo físico en la tabla `comparaciones_conteo`

Estado: Adoptado (registrado a posteriori por ingeniería inversa)   Fecha del registro: 2026-11-27

## Contexto

La historia H-05 pide «detectar y **documentar** los descuadres». ADR-002 menciona que el conteo físico se escribe con un repositorio propio, pero ni ADR-002 ni el modelo de datos de la Fase 1 (6 tablas) describían dónde se guarda.

## Decisión

Existe una séptima tabla, `comparaciones_conteo` (creada por `data/seed.py`), y `RepositorioComparacion.guardar_comparacion()` inserta una fila por cada repuesto comparado: `fecha_hora`, `codigo`, `nombre`, `sistema`, `conteo`, `diferencia` y `descuadre` (0/1). La tabla no tiene clave foránea: guarda una copia del código y el nombre del momento.

## Consecuencias

- *Positivas:* queda un histórico de descuadres (`tests/test_comparacion.py::test_comparacion_se_persiste`).
- *Negativas:* no hay pantalla ni endpoint para consultar ese histórico; hoy tiene 0 filas. Si el guardado falla, solo se registra en el log (`logger.exception`) y el usuario igual ve el resultado.
- La regla de la S7 «PROHIBIDO crear tablas nuevas» no se incumple: la tabla ya existía en el proyecto base (`fc44cd0`).

## Evidencia

`data/seed.py` (`CREATE TABLE IF NOT EXISTS comparaciones_conteo`), `app/modules/comparacion/repositorio.py`, `app/modules/comparacion/router.py`.
