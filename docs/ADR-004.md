# ADR-004 · El asistente es un agente con herramientas MCP por stdio, no un prompt con contexto armado por `GeminiGateway`

Estado: Adoptado (registrado a posteriori por ingeniería inversa)   Fecha del registro: 2026-11-27

## Contexto

El diseño de la Fase 1 (tarea 11.3) preveía que el router del asistente pidiera contexto a `McpReadClient` y enviara un único prompt a `GeminiGateway`. En el proyecto final (H-09) el instructivo pedía un agente que **decidiera** qué consultar, con herramientas MCP. El código actual implementa esto último, pero ningún ADR lo registraba.

## Alternativas consideradas

1. **Prompt único con contexto** (`McpReadClient` + `GeminiGateway`): simple, pero el router tendría que adivinar qué datos necesita cada pregunta.
2. **Agente con herramientas MCP, Servidor MCP como proceso hijo por stdio**: el modelo elige la herramienta y el servidor no necesita puerto ni una terminal aparte.
3. **Agente con Servidor MCP en red** (HTTP/SSE, puerto 8001): habría que encender otro proceso y abrir un puerto.

## Decisión

Se adopta la alternativa 2.

- `AgenteTaller` (`agente/agente.py`) enciende `agente/servidor_mcp.py` con `StdioServerParameters(command=sys.executable, …)` en un hilo propio (`ConexionMCP`), lo mantiene encendido entre preguntas y lo vuelve a encender si se cae.
- `app/main.py` lo «precalienta» al arrancar, salvo con `MODO_TEST=1`.
- El router del asistente solo hace de puente y registra la trazabilidad.

## Consecuencias

- *Positivas:* una sola terminal; el modelo decide la consulta; las herramientas se prueban solas (`tests/test_agente.py`); el servidor también puede usarse desde otro cliente MCP (`python agente/servidor_mcp.py`).
- *Negativas:* `GeminiGateway` y su prueba quedan como código heredado. Los módulos H-02 a H-06 siguen con `McpReadClient` en modo stub, así que hay dos caminos de lectura. No se puede usar `uvicorn --reload` en Windows.

## Evidencia

`agente/agente.py` (`ConexionMCP`, `AgenteTaller.responder`), `agente/servidor_mcp.py` (`mcp.run()` por stdio), `app/main.py` (`precalentar`), `tests/test_agente.py::test_servidor_mcp_real_expone_al_menos_dos_herramientas`.

## Criterio de reversión

Volver a un Servidor MCP en red si se necesita compartirlo entre varios procesos o máquinas.
